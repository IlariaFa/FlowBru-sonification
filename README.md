# Mon projet de sonification

Ce projet permet d'apprendre à transformer des données
en sons avec la bibliothèque Python STRAUSS. Ils seront utilisé les données de FlowBru pour analyser le rapport entre pluie et niveau d'oxygène dans la Senne. 

## Objectifs

- Comprendre les bases de STRAUSS
- Produire une sonification rigureuse sur les données hydrologique choisi et leurs rapports
